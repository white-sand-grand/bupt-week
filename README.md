# BUPT-week

[![gate](https://github.com/white-sand-grand/bupt-week/actions/workflows/gate.yml/badge.svg)](https://github.com/white-sand-grand/bupt-week/actions/workflows/gate.yml)
[![deploy](https://github.com/white-sand-grand/bupt-week/actions/workflows/deploy.yml/badge.svg)](https://github.com/white-sand-grand/bupt-week/actions/workflows/deploy.yml)

某学委因日常在群里分发作业不便做的给北邮学生的个人课表 / 作业 / 下载文件的小站：**查课表、看作业、下课件、交作业一键直达**，微信里也能用。

- **在线地址**：<https://white-sand-grand.github.io/bupt-week/>
- 一套学号密码登录，课表、作业、课件、班级四个标签页
- 前端部署在 GitHub Pages，后端跑在 Cloudflare Workers——**前端不直接接触任何学校域名，也不持有任何密码**

本人信奉 "Less is more" 的设计理念，不做除实用功能之外的个性化设计和其余臃肿功能。

由于初建，欢迎在 issue 反馈 bug，出于持续提升原因可能会有网站波动。

---

## 功能

**统一登录**
- 一个表单登两个系统：课表来自教务处（jwgl），作业来自云邮教学空间（ucloud），二者共用统一身份认证，一次认证各取所需
- 微信内打开自动识别企业微信身份，免输密码（基于校方 mc-wx 静默授权，回流带一次性 state 防劫持）
- 会话持久化：正常使用自动续期（滑动 7 天），30 天绝对上限到期需重登；每小时静默探活，token 过期前完成续期
- 由于微信打开的具体提示限制会有进入缓慢现象，等一会就好

**课表**
- 数据源为移动教务（jwglweixin，公网可达，校外可用），教务处 PC 版为回退源
- 跨节课卡片纵向铺满全部节次；同名课程固定同色
- 节次时刻**北京 / 海南双校区**可切换（双显默认），悬停课程卡可见两校区具体起止时间
- 周次补齐到学期末（含期末空周），逐周本地缓存，切周不联网；「今天」列自动定位

**作业**
- 全量列表按紧急度排序：已逾期 → 今天/明天截止 → 一周内 → 待完成 → 已提交 → 往期未交
- 作业栏默认只列**未提交**的，点「显示全部」切换完整列表（含已提交）
- 未提交作业显示**距截止倒计时（精确到分钟）**与截止进度条（颜色即紧急度）
- 只显示本学期；截止时间一律按北京时间解释，不随设备时区漂移
- 附件在卡片内直接下载（服务端代理，绕开云邮存储的防盗链限制）
- 「去交作业」直达该作业的提交页，**不做本网站提交**，防止出现提交不上问题。初次登录云邮会经过一次统一验证，可以重新点一遍「去交作业」来直接跳转该页

**课件**
- 按老师建的课程目录结构，一门课的全部资料一页铺开，多份课件直接下载（与作业附件同一套下载进度显示）
- 外部链接类资料直接新标签打开；列表按课程本地缓存，切课不重复加载

**班级**（同学间共享作业）
- 创建班级（名称 + 密码）得 8 位班级号（无易混字符，点击即复制），同学凭班级号 + 密码加入；可加入多个班
- 任何成员都能手动录入作业（必填：标题 / 科目 / 内容；截止时间可选），全班共享
- 作业栏里班级作业按科目分组、带来源班级标签，排序 / 倒计时与云邮作业同构
- 班级作业可点「确认完成」移出未提交列表，在「显示全部」中可改回未完成；完成标记按账号保存在当前浏览器
- 密码 PBKDF2 加盐存储，明文不落任何地方；班级创建者可解散班级，录入者可删自己录的作业

## 使用

1. 打开 <https://white-sand-grand.github.io/bupt-week/>（微信内打开会自动识别，无需输密码）
2. 浏览器里用学号 + 统一身份密码登录；微信内识别成功后，若要看课表，在课表页黄条里**补填一次教务密码**（通常与统一身份密码相同），之后 30 天内不再询问
3. 课表页看课、作业页看作业、班级页和同学共享作业

> 网络说明：后端在 `*.workers.dev` 上，部分网络可能无法直连。若页面打得开但登录失败，换网络再试；自托管后端绑定自定义域名可彻底解决，见部署文档。

## 自托管

想跑一份自己的实例：后端可部署到 Cloudflare Workers（也可跑在任意 Node 服务器上），前端发布到任意静态托管即可；完整步骤、变量配置与安全建议见 **[docs/deployment.md](docs/deployment.md)**。

## 安全与隐私

**密码与凭证**

- 密码只在登录 / 补填的那一次请求里使用，不写入任何存储、日志或响应（有自动化测试守着）；统一登录时教务与云邮两侧凭证各自独立，一侧失败不影响另一侧的密码处理
- 退出登录后浏览器与服务端的会话同时销毁；浏览器本地只保留会话编号、学号、姓名、过期时间
- 会话有时限：正常使用自动续期（滑动 7 天），30 天绝对上限到期必须重登；统一登录与班级加入都有失败限速，防密码爆破

**传输与隔离**

- 前端是纯静态页面，不直接接触任何学校域名，也不持有任何密码——学校系统的登录凭证全程不出后端
- 不做任何统计埋点、不加载第三方脚本、不向后端之外的任何地址发送数据；后端读取的只是**你本人**的课表、作业与课件

**下载代理**

- 课件与附件经服务端代理下载：只认学校文件存储这一个域名，其他一律拒绝（防止代理被当成开放中继）；外站引用打不开；转发请求时不携带任何身份凭证

**班级功能**

- 班级密码加盐哈希后存储，明文不落任何地方；持有班级号 + 密码即可录入共享作业——请只把班级号和密码告诉信得过的同学，录入的内容全班可见

**自动化守门**

- CI 门禁在每次提交时运行：依赖漏洞审计、仓库密钥扫描（连未跟踪文件也扫）、安全响应头探活、构建产物体积预算；测试与构建不过关不发布

**自托管须知**

- 自托管实例的会话数据存在你自己的存储里，你就是它的管理者和责任人：务必配置 `CORS_ORIGINS` 来源白名单、给登录接口加限速规则、全程 HTTPS；详见 [docs/deployment.md](docs/deployment.md)

## 不是爬虫

**三个数据源，各走各的协议**

- 课表：主源移动教务（jwglweixin，公网可达，校外可用），回退源教务处 PC 版（jwgl，仅校园网）
- 作业与课件：云邮教学空间（apiucloud）
- 班级作业：同学之间手动录入，完全不经学校系统

**接口是复用来的**

- 所有接口、字段与请求头都来自学校自己的前端 bundle 与官方参考实现，和云邮前端、企业微信端在用的是同一套
- 只有固定的几个端点；作业列表会按「本人已选课程」逐个回填课程名，此外没有无目的的遍历、没有分页扫全站、没有链接发现
- 每一次取数都由你的一次点击触发；没有定时抓取，仅每小时一次会话探活（只为续期，不取数据）

**只读本人的数据，不做任何写操作**

- 读取范围限于你本人权限内的课表、作业与课件
- 不提交作业、不评教、不签到——「去交作业」是把你的浏览器直接送到官方提交页，本站不代做提交

**文件下载经服务端代理，但不落地**

- 附件与课件由后端换成学校文件存储的签名直链后立即转发给浏览器：不落地存储、不留副本、转发时不携带任何身份凭证
- 代理只认学校文件存储这一个域名，其他一律拒绝（防止被当成开放中继）

**由于经常有人觉得是爬虫而不得不说明的和爬虫的区别**

| | 爬虫 | 本站 |
|---|---|---|
| 范围 | 遍历、发现、尽可能多 | 固定几个端点，只读本人权限内的数据 |
| 数据去向 | 建库、聚合、二次分发 | 只渲染给本人看 |
| 写操作 | 常见 | 完全没有 |

## 云端存什么

不存云端的

- 课表、作业、课件的原始数据：后端是纯透传薄层——从学校取到 JSON/HTML、解析、立刻返回给浏览器，不写任何存储
- 文件本身：/file 代理是无状态字节转发，附件和课件不落地、不留副本（server/routes/proxy.js）。
- 这些数据只缓存在用户自己的浏览器里：课表按周缓存、作业列表缓存（stale-while-revalidate）。

存云端的只有两样：

**1. 会话凭证 —— SESSIONS namespace**

注意这是「派生凭证」，既不是密码也不是课表作业内容：

| kind | 存什么 |
|---|---|
| jwgl | 教务处 Cookie | 
| jwglweixin | 移动教务 token |
| ucloud | access_token + refresh_token + userId |

7 天滑动 + 30 天绝对上限，isLive() 按 expiresAt 判活、过期即删（server/storage/kv.js:37）。另有一个 wecomctx:{state}——企微登录时暂存的 CAS 匿名会话，15 分钟 TTL、用完即删。

**2. 班级功能数据 —— CLASSES namespace：全项目唯一真正持久化的业务数据**

前端 localStorage（在用户浏览器，不上传）

bupt-week-ucloud-auth / bupt-week-jwgl-auth   sessionId + 学号 + 姓名 + 过期时间
bupt-week-timetable-v1                        按周课表缓存（按 username+mode 隔离）
bupt-week-assignments-v1                      作业列表缓存（按 username 隔离）
bupt-week-class-completed-v1:{username}       班级作业「确认完成」标记
